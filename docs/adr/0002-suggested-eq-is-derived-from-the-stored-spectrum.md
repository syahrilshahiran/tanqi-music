# The Suggested EQ is derived from a Track's stored spectrum, against a built-in reference

An Audio analysis stores the Track's measured spectrum (29 third-octave levels), loudness and peak, and the Suggested EQ is computed from them when the Track loads, against a built-in reference curve and its normal spread, then scaled by the Suggested EQ strength. We considered storing the finished bands, as the app did before, but then every change to the reference, the strength or the rules for flagging a band needs every Track decoded again; and we considered a fixed textbook curve, but the sources (see `docs/eq-analysis-research.md`) do not support Harman, equal-loudness or a universal tilt as a target for music, so the reference is measured from real albums instead and its genre bias is documented. The cost is a version number on each analysis, so analyses made before the spectrum was stored are treated as needing a re-analysis (they keep working until then), and a reference that has to be re-measured and shipped when we decide to change it.
